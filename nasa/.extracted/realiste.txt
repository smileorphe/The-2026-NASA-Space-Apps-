Fiche réalisme 3D : faire mieux que le
prototype

Tout ce qu'il faut pour obtenir une vue de Mars crédible pour un jury d'experts : la chaîne de
production, les données, les techniques de rendu, les références et la checklist. Fichiers fournis avec
cette fiche : prep.py , index.html et le dossier assets/ .

01 Le principe : le réalisme vient des données, puis de la lumière

  Ordre d'importance : 1. un vrai relief précis · 2. une vraie texture · 3. un soleil bas et des ombres
  justes · 4. la brume de poussière · 5. les rochers · 6. le post-traitement. Ne passez à l'étape suivante
  que quand la précédente est bonne.

06 Utiliser les fichiers fournis

Lancer le prototype sur votre PC

1. Mettre index.html, prep.py et le dossier assets/ dans un même dossier

2. pip install numpy scipy pillow               (et rasterio pour les vraies données)

3. python prep.py                                régénère assets/

4. python -m http.server 8000                    serveur local

5. Ouvrir http://localhost:8000 dans Chrome

Ouvrir index.html par double-clic ne fonctionne pas : le navigateur bloque le chargement des fichiers
locaux. Il faut le serveur local de l'étape 4.

Brancher les vraies données NASA le jour J

Dans prep.py , remplacez la ligne dem, craters, sandmask = synth_dem() par la lecture du fichier de
relief :

  import rasterio
  with rasterio.open("DTM_Jezero.tif") as src:

          dem = src.read(1).astype("float32")
          dem[dem == src.nodata] = np.nan
  # découper la zone de 2 km, remplir les trous, ramener à 2049 x 2049
  dem = dem[r0:r1, c0:c1]
  dem = np.where(np.isnan(dem), np.nanmean(dem), dem)
  dem = ndimage.zoom(dem, 2049 / dem.shape[0], order=1)
  craters, sandmask = [], np.zeros_like(dem)

Pour la texture, remplacez le calcul de l'albédo par l'orthoimage HiRISE redimensionnée en 2048 ×
2048. Les pentes, la carte de coût, les rochers et l'itinéraire se recalculent automatiquement à partir du
vrai relief.

07 Checklist réalisme avant la démo

   Comparaison côte à côte avec une vraie photo Mastcam-Z : couleur du sol, du ciel, dureté des
   ombres.
   Aucune ombre « cuite » dans la texture qui contredit le soleil.
   Pas de texture floue ni étirée en vue astronaute.
   Les rochers touchent le sol (pas de rocher qui flotte).
   L'horizon disparaît dans une brume orangée, sans bord visible.
   Au coucher du soleil, le halo bleu autour du soleil est visible.
   Au moins 30 images/seconde sur le PC de démo, branché sur secteur.
   Chaque couche affiche sa source NASA ; les simulations sont étiquetées comme telles.
   La démo tourne sans internet.
